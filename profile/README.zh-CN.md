## 研究与工程

- **让脑拓扑参与连续控制** — 将生物脑拓扑嵌入脉冲神经网络，以 ARS 进化策略优化连接权重，在 MuJoCo 连续控制任务中探索结构与学习的协同。
- **从整张切片到病灶定位** — 围绕软组织肿瘤分级与皮肤病理图像，研究基于 Virchow2 的多实例学习、条件分割，以及基于 DINOv2 的病灶识别与弱监督分割。
- **连续时间的生理信号建模** — 结合多模态生理信号、时频分析与 Neural ODE，建模术中生理变化并研究低血压等高危事件的提前预测。
- **连接类脑算法与低功耗硬件** — 搭建包含 LIF / Izhikevich 神经元和 STDP 在线学习的仿真验证平台，参与神经形态芯片的算法设计、硬件映射与协同迭代。
